# Видеоконтроль опасных зон и СИЗ на складе

Система смотрит видео с камер склада и сообщает о нарушениях техники безопасности:

- человек слишком долго стоит в опасной зоне (зона работы погрузчика, проход у стеллажей во время загрузки);
- человек работает без каски или сигнального жилета.

Сейчас такие нарушения ищут вручную по записям, и большинство из них никто не замечает. Здесь система находит нарушение сама и присылает оператору тревогу с коротким клипом, а оператор только подтверждает её или отмечает как ложную.

Подробно про задачу, метрики и план решения — в [дизайн-документе](docs/ml_system_design_doc.md).

## Как это работает

1. Из видеопотока берутся 2–5 кадров в секунду.
2. Детектор находит людей, каски и жилеты.
3. Трекер ByteTrack ведёт каждого человека между кадрами.
4. Правила по зонам, размеченным для каждой камеры, решают, есть ли нарушение.
5. При нарушении сохраняется клип и уходит тревога оператору.

Решения оператора потом используются как разметка для дообучения модели.

## Как начать работать с репозиторием

```bash
git clone https://github.com/<твой-ник>/<имя-репозитория>.git
cd <имя-репозитория>

python -m venv .venv
source .venv/bin/activate        # на Windows: .venv\Scripts\activate

pip install pre-commit ruff
pre-commit install               # хуки будут запускаться на каждом коммите
```

Проверить весь код вручную:

```bash
pre-commit run --all-files       # все проверки разом
ruff check .                     # только линтер
ruff format .                    # только форматирование
```

## Как ведётся разработка

Проект делается в формате менторства: я проектирую систему и пишу ML-часть, ученики разрабатывают сервисы вокруг неё. Все изменения идут через отдельную ветку и pull request с ревью, прямых коммитов в `main` нет.
